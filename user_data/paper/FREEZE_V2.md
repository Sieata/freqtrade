## 二、冻结参数

```
4h K线 | 做多 | 八品种（BTC ETH SOL XRP ZEC BANK CYS HYPE）
窗口：周六日 + 周一美股盘前（北京时间21:00前）
入场：前一根K线跌 >2% + 当前阳线 + 量>0
风控：-10% 硬止损 | 尾随 1.5%激活 / 0.2%步长 | 8% 止盈
仓位：stake_amount=unlimited, max_open_trades=1, tradable_balance_ratio=0.99
关键差异：不写任何 exit 信号列（V1 的 EMA20 exit 信号会意外阻挡同根K线入场）
```

## 三、与 V1 的差异（两处）

1. **去掉 EMA20 入场阻挡**：V1 中 `populate_exit_trend` 的 EMA20 信号即使
   `use_exit_signal=False`，也会在 `check_for_trade_entry` 中阻挡同根 K 线入场。
   去掉后 2022-2026 多 37 笔，利润 $206,386 → $255,811。
2. **尾随步长 0.3% → 0.2%**：更贴近峰值锁利。调参窗（2022-2024）为最优且非边界值，
   逐年稳定 +13~16%。

## 四、样本外验证结果（按 STRATEGY_WORKFLOW 标准）

### 调参 / 检验纪律

- 调参只用 2022-2024（`--timerange 20220101-20250101`），2025-2026 全程未参与优化。
- 调参窗结论：步长 0.2% 最优（$23,820 vs 基线 $18,576，+28%）；ROI 0.06、止损 -12%
  的优势仅出现在样本外，故未纳入默认参数（避免在测试集上事后挑选）。
