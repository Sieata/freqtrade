## 三、机制与定位

- **全市场去杠杆共振条件押注**：中期上升趋势中的"急跌 + OI 急缩"= 回调买点；下跌趋势中 = 下跌中继（V1 死因，已被 30d 动量过滤修复）。
- **低频、单年集中**（RESEARCH 26.14）：2024 年 92% 利润来自 3 个"多币同日 OI 齐缩"事件，五年仅出现 3 次，其余年份贡献≈0，2026 转负。
  - ⚠️ 语义澄清（26.24，2026-11-08 轮43）：这里的"3 次"是**利润集中的大额共振日**，不是信号事件总数。实测 TEST 44 笔分布在 **22 个独立事件簇**（中位簇大小 1、最大 3）。因此下方的「≥20 笔」判据 ≈ **10~15 个独立事件**（合理样本），但**利润/PF 仍由罕见大额共振日主导**——读判据时须并列看「笔数/胜率」与「窗口内是否含大额共振日」，谨防胜率被单一大共振日绑架。
- **参数存疑**（26.12/26.14.1）：`oi_quantile` 0.05→0.15 TEST 多赚 66%、TOP5 蓝筹同向复现，但 OOS 样本不足以下结论。
- **paper 的使命**：正是补样本到统计显著所需（n=62 → 更多 OOS）。判据意义在方向与样本积累，不在首月数字。

## 四、forward-test 判据

| 指标 | 绿灯 |
|---|---|
| 样本量 | ≥ 20 笔平仓（事件臂低频，给足 6 个月） |
| 胜率 | ≥ 45%（VAL 62%，留足波动余量） |
| 最大回撤 | ≤ 10%（VAL 2.4%） |
| 总利润 | > $0 |

**只记录，不改参。至少 3 个月 / 20+ 笔后再下第一次判断。**

### 4.1 预注册判定流程（2026-11-08 冻结，避免事后合理化）

- **触发**：累计已平仓 ≥ 20 笔 **且** 运行 ≥ 3 个月（以先到者不豁免，两者同时满足才读第一次判定）。
- **四门齐判**：样本量 / 胜率 / 最大回撤 / 总利润 **同时** 满足 → 绿灯；任一不满足 → 该次判为"未过"。
- **期中只记录，不判**：未达触发门槛前，weekly `paper_status.py` 只入账（笔数/胜率/回撤/累计利润 → `logs/daily_ops.jsonl`），**不因期中数字好坏提前改判或调参**；期中数字不作为独立样本外证据（等价于 VAL 窥视台账原则）。
- **不达标的处置**：未过 → 本臂维持 paper，继续积累（OI 为事件臂，低频属正常）；**不**凭单次未过就调 `oi_quantile`（调参需新 SHA + 重走 VAL + 记台账，见 26.12）。连续两个 20 笔窗口均未过 → 提交用户决定是否降级归档。
- **唯一"提前止损"**：回撤突破 ≤ 10% 门（钱包口径）或出现连续不可解释亏损（数据/执行异常，非策略范畴）→ 立即停机排查，不计入判据。
- **达标后的措辞纪律**：绿灯仅表示"paper 方向与样本支持继续观察/小资金试跑"，**不等于实盘许可**；实盘仍需用户在授权内单独决定，并遵循 CORE 池 + 固定每笔本金口径。
