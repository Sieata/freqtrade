## 〇、结论先行

1. **仓位轴（降低单笔敞口）在两套池子上都成立**：现行 99% 满仓复利在所有尺度无关指标上最差。
   改成固定 $1,000/笔（或 25%–50% 比例仓）即可显著改善 PF / SQN / p 值 / 回撤。
2. **槽位轴不迁移**：TOP10 上 3 槽是「89% 利润 / 30% 资本、SQN 5.86」的好配置；
   冻结 8 品种池上 3 槽反而 PF 2.57→1.95、p 2.5e-7→2.7e-6，是**两头不讨好**的配置。
3. **冻结池上若要多槽，直接开到有效池规模（5 槽）**，不要停在 3 槽：
   5 槽固定 $1,000 利润 +38%（+$3,009→+$4,142），PF 2.00、SQN 5.14、p 4.2e-7、回撤 4.60%。
4. **建议**：paper 池维持 8 品种时，优先「固定 $1,000/笔」；多槽只在能接受 PF 下降、
   换取 +38% 利润时开 5 槽。若想换 TOP10，属于**另一次冻结**（池子变了），不能当 config 微调。

## 一、两套口径与差异来源

| 项 | TOP10 评估池 | 冻结 paper 池（`pairs_paper_v2`） |
|---|---|---|
| 品种 | BTC ETH BNB XRP SOL TRX HYPE ZEC DOGE XMR | BTC ETH SOL XRP ZEC BANK CYS HYPE |
| TEST 内有效品种 | 9（HYPE 仅 2025-05 后有数据） | 明显更少（HYPE 同；BANK/CYS 历史短） |
| 1 槽 TEST 笔数 / 拒单 | 333 / 416（拒绝 55.5%） | 256 / 200（拒绝 43.9%） |
| 信号密度 | 高，周末常有多品种同时触发 | 低，多槽主要在**同一周末加仓**，不是跨品种分散 |

> 这解释了为什么多槽在 TOP10 上既能加利润又能提质量，在 8 品种池上却主要是「同向加仓」：
> 池子窄时，多出来的槽位接的是同一波周末下跌里的相关信号。

## 四、建议（按目标二选一）

### 方案 A — 统计质量优先（推荐先做）

| 项 | 值 |
|---|---|
| 池 | 维持冻结 8 品种 |
| `stake_amount` | 固定 **1000** |
| `max_open_trades` | **1**（或维持现行槽位） |
| 钱包 | ≥ $1,200；实盘建议 $2,000+ |
| 依据 | PF 2.57 / SQN 5.30 / p 2.5e-7 / 回撤 2.43%，全面优于现行 99% 复利 |

这是**只改 sizing、不改池、不加并发**的最小改动，也是两套池子上都成立的结论。

### 方案 B — 利润优先

| 项 | 值 |
|---|---|
| 池 | 维持冻结 8 品种 |
| `stake_amount` | 固定 **1000** |
| `max_open_trades` | **5**（有效池宽上限；开 8 与 5 等价） |
| 钱包下限 | 5 × 1000 × 1.2 = **$6,000** |
| 依据 | 利润 +38%（$3,009→$4,142）、回撤 4.60%、PF 2.00、p 4.2e-7 |

代价：PF 2.57→2.00、p 值变差约 1.7 倍。**不要用 3 槽**（利润只 +24%，PF 掉到 1.95）。

### 方案 C — 换 TOP10 池（另一次冻结）

若决定把 paper 池从 8 品种换成 TOP10，则适用 17.7 的结论：
`max_open_trades = 9`（有效池宽）、`tradable_balance_ratio` 作风险旋钮（0.99/0.5/0.25 均可）。
但这是**池子变更**，不是本次 config 微调；需单独走冻结/评审，且 V2 的 8 品种冻结记录保持不动。
