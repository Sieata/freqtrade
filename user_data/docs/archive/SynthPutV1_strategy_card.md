## 0. 一句话

用**高杠杆多腿的保证金当"权利金"**,构造一份针对暴跌的合成看跌期权:暴跌时多腿被强平(亏损封顶在保证金),空腿跟跌赚取更大的收益。**不是免费午餐,是一份带尾部风险的"卖保险"结构。** 之前已确认:横盘/小涨时两腿对冲净值≈0,只付资金费;暴跌时多腿强平、空腿赚;极端暴涨时空腿被强平,才是真正的尾部风险。

---

## 1. 收益结构(数学)

设两腿名义本金相等 `N`(保持 delta 中性),多腿杠杆 `L_L`(高)、空腿杠杆 `L_S`(低),保证金分别为 `M_L = N/L_L`、`M_S = N/L_S`。

| 行情 | 多腿 | 空腿 | 净值 |
|------|------|------|------|
| 横盘 / 小涨(< 1/L_S) | 浮盈 | 浮亏 | ≈ 0 − 资金费净值 |
| **暴跌**(x > 1/L_L) | 强平,实亏 ≈ −N/L_L | 跟跌赚 N·x | **N·(x − 1/L_L) − 成本** |
| 极端暴涨(y ≥ 1/L_S) | 赚 N·y | 强平,实亏 ≈ −N/L_S | N·(y − 1/L_S),受强平滑点拖累 |

**盈亏平衡公式(暴跌方向):**
```
x* ≈ 1/L_L + (手续费 + 裸空期资金费)/N
```
多腿 20x → 平衡点 ≈ 跌 5%;10x → ≈ 10%。**权利金(多腿保证金)与平衡点绑定:**杠杆越高权利金越便宜、平衡点越浅,但强平越频繁、滑点越不可控。

**关键取舍:真正该管理的是空腿杠杆 `L_S`。** 空腿是净值大头,它的强平线决定这个结构在极端暴涨时崩不崩;`L_S` 越小越安全,但资金占用越大。

---

## 2. 成本模型

1. **资金费**:两腿开仓期间净值≈0;多腿强平后的**裸空窗口**,若资金费被砸成深负(暴跌恐慌时常见),空头反而要付钱——在你想持有空单的时候。
2. **强平滑点**:多腿强平是市价单,极端行情下滑点放大;保险基金介入 / ADL 可能让实亏 > 保证金。
3. **手续费**:双开 + 强平 + 平空,约 3-4 次 taker(每次约 0.04%),来回 ≈ 0.12%-0.16%。

## 3. 风险清单(按严重度)

| # | 风险 | 说明 | 对策 |
|---|------|------|------|
| 1 | **强平后裸空 + V 型反弹** | 暴跌后恰是波动率最高、最容易急拉的窗口,对冲结构在此时失效,反弹吃掉全部利润 | 裸空窗口设保护止盈/反向止损;暴跌兑现后主动离场 |
| 2 | **空腿被极端暴涨强平** | 实际尾部风险,亏 `M_S`(远大于权利金) | `L_S` 取最低档;设 rally 止损 |
| 3 | **资金费反噬** | 裸空窗口深负资金费 | 计入成本模型;选 funding 极正时入场则反赚 carry |
| 4 | **幸存者偏差** | 晒单都是赚的,没人晒"两腿来回被扫、来回补保证金" | 只信回测,不信晒单 |
| 5 | **强平滑点 > 保证金** | 极端行情实亏超权利金 | 留缓冲保证金;不追最高杠杆 |

## 4. 双腿版 vs 单腿翻译版

| | 双腿版(原始结构) | 单腿翻译版(fragile short) |
|---|---|---|
| 结构 | 同合约同时持多、空两腿 | 只做空,宽止损当权利金 |
| 实现 | 需 **hedge mode**(Binance 双向持仓)或两个账户;**freqtrade 不支持同合约同持多空** | freqtrade 期货可跑(`can_short=True` + 低杠杆) |
| 优势 | 忠实还原,横盘几乎不亏净值 | 无锁仓资金费;结构简单可回测 |
| 劣势 | 无法在 freqtrade 体系内验证;强平滑点难回测 | 横盘/续涨时持续吃止损(权利金),不再是"免费期权" |

**结论:双腿版只在纸面/独立脚本验证;要进 freqtrade 体系,必须先验证单腿翻译版的核心假设。**

## 7.5 双腿结构全路径回测(2026-08-10)

`user_data/scripts/synth_put_backtest.py` 独立模拟器(20x 多 / 2x 空 / 行权价滚动 10% / 真实 funding):

| 假设 | BTC | ETH | BNB | SOL | DOGE |
|------|-----|-----|-----|-----|------|
| 基准(滑点0.5% 维持差0.4% 捕获10%) | -204% | -377% | -315% | -325% | -113% |
| 现实(滑点0.2% 维持差0.4% 捕获15%) | -140% | -81% | -12% | -11% | -75% |
| 最乐观(零滑点 零维持差 捕获20%) | +129% | +250% | +73% | +361% | -40% |

- **基准假设下五品种账户全部在 2021-2022 归零**(BTC 2022-04 / ETH 2021-10 / BNB 2022-10 / SOL 2021-11),同期 B&H +121%~+4667%。
- 机制:93% 的爆仓周期弹回行权价,每次净亏 ≈ -105U(权利金 500 + 维持差 40 + 滑点 50 + 费 16 − 空腿回收 460);深暴跌兑现 +850U/次,只覆盖一半。
- 只有"强平零滑点 + 零维持差 + 暴跌都走 20%"三个同时成立才 4/5 转正——每条都违背交易所机制和 §7 的波动率数据。
- **结论:结构作为 always-on 策略被数据否决,不是"贵保险",是系统性把摩擦转化为亏损的机器。**

把 always-on 改成"信号触发才开仓、patience 内未强平就平仓",开错成本压到 ≈16U/手(`synth_put_timed.py` / `synth_put_precrash.py`)。测 7 类信号 × 阈值 × patience:

- 未测:订单流 / 持仓量 / 多空比(本地无数据)——若真要深挖暴跌预测,这是唯一没被穷尽的信息源,但超出当前数据范围。

### 7.7 跨周期验证(2026-08-10)——1d 的"转正"是日线假象

下载 1h/1d futures + 补齐五品种 funding,同套信号按真实时间归一化跑 1h/4h/1d:

| 周期 | 结论 |
|------|------|
| 1h | 全灭(弹回陷阱最重) |
| 4h | 2021 效应,样本外全负 |
| 1d(日线执行) | **OOS 4/5 转正**——全项目首次 |
| **1d 信号 + 4h 真实执行** | **只剩 ETH +2237 / DOGE +6398,2/5** |

**关键教训:SOL 在日线执行下 OOS +8157,换 4h 执行变 -1657;BTC +374 → -1520。** 日线模拟看不到日内反弹,把"该止损的空头"算成了"捕获暴跌"。**信号必须在真实粒度下验证,否则"转正"是假的。**
