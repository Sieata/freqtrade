## 一、问题：现行门禁与信号策略的结构性错配

现行门禁（利润>0 / PF>1.0 / **≥80% 品种盈利** / VAL dd≤30%）对"全时段、全池覆盖"的
引擎策略（V2）是合理的；但对事件触发型策略存在系统性错配——事件只在有 edge 的品种/时段
触发，品种间分布天然不均。三例实证：

| 案例 | 利润/PF/dd | 品种宽度 | 集中度 | 结构性原因 |
|---|---|---|---|---|
| FS（FundingSqueezeV1L） | 全过 | 70–74% | ZEC 13–17%（非 pump） | funding 极端事件集中于高波动币 |
| BigMoveV1 | **PF 2.33–3.21 全库最高**、dd 2.2–2.6% | 5/8–6/9 | ZEC/DOGE 68–69% | 低频肥尾：少数大赢家 |
| OIFlushV2 | 全过（TEST PF 3.84/4.15） | TEST 8/8、11/11；VAL 7/9、8/12 | 无集中度警告 | 事件频率极低（并发 0.1 仓） |

V2 能过 80% 线是因为周末效应全品种同源——这不是"V2 更好"，而是"策略类型不同"。

## 二、提案：双层级门禁

### Tier A —— 引擎策略（现行门禁，不变）
定义：全时段全池覆盖的主力策略（现库：V2）。四条门禁维持原样。

### Tier B —— 事件臂策略（新增评估框架）
定义：事件触发、低并发、定位为组合补充的策略（FS / OIFlush / BigMove 类）。

**硬性门禁（全过才可进 paper）：**
1. TEST+VAL 利润 > 0 且 PF > 1.0（TOP10 口径，双池）
2. VAL dd ≤ 30%
3. 集中度红线不变：单品种利润占比 ≤ 50%，且其利润不得 80% 集中于单年（防 pump 红线保留）
4. 与现有引擎的 K 线级信号重叠 ≤ 30%（`fs_portfolio_check` 模式度量）

**组合增量门禁（替代品种宽度）：**
5. TOP10 口径下，加入主力（V2）后组合年化提升 ≥ **+3pp**
6. 合并最差月（按双臂资金归一，÷2）≤ 主力单独最差月 × **1.5**
7. 逐年收益率（每年重置 $1,000）：VAL 段负年 ≤ 1 个，且最深 ≥ **-15%**

**定版路径**：Tier B 以 paper 证据定版（6 个月 FREEZE 判据，逐年收益率口径），
不单独跑现行门禁。

## 三、现行候选 Tier B 实测结果（2026-08-29，`tier_b_eval.py`，TOP10 口径单运行数据源）

| 候选 | 门禁4 重叠 | 门禁5 增量(TEST/VAL) | 门禁6 最差月归一(TEST/VAL) | 门禁7 VAL 负年 | 判定 |
|---|---|---|---|---|---|
| **BigMoveV1** | 0% ✅ | +5.4pp / **+15.6pp** ✅ | 0.50x / 0.50x ✅ | 0 个 ✅ | **✅ 全过** |
| **OIFlushV2** | 0% ✅ | +7.9pp / +5.2pp ✅ | 0.62x / 0.52x ✅ | 1 个（-11.0%）✅ | **✅ 全过** |
| **FS（V1L）** | 2–3% ✅ | +10.3pp / +9.2pp ✅ | **1.52x ❌** / 0.72x ✅ | 1 个（-11.6%）✅ | ⚠️ 仅 TEST 门禁6 边缘超线 |

- 组合年化（TOP10 钱包口径）：V2 单独 +19.2%(TEST)/+16.6%(VAL)；加 BigMove → +24.6%/+32.2%；
  加 OIFlush → +27.1%/+21.9%；加 FS → +29.5%/+25.8%。
- **BigMove 与 OIFlushV2 在 Tier B 框架下全过**——BigMove 的 VAL 增量最高（+15.6pp）且零负年；
  OIFlush 次之。FS 唯一瑕疵是 TEST 合并最差月归一 1.52×（草案线 1.50×，差 0.02），
  属于"批准时是否放宽至 1.6×"的裁量项。
- 数据源：各候选最新 TOP10 验证报告的两腿 zip（单一并发口径）；V2 基准同源。
