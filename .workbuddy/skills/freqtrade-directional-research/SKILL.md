# 单品种方向性策略（CTA）可行性研究套路（freqtrade 仓库）

## 先读

`RESEARCH.md` 第二十三节（ETH CTA 首例）。工具：`user_data/scripts/eth_cta_research.py`。
复制该脚本改 `SYM`/信号族即可做 BTC/SOL 等其他品种。

## 核心纪律（照抄）

1. **预注册信号族，不做搜索**。写死经典参数再跑（TSMOM k∈{10,30,90,180}、
   MACROSS {10x50,20x100,50x200}、DONCHIAN {20,55}）。事后加参数 = 挖掘，报告里要明说。
2. **日频口径**：4h K 线 `resample("1D").last()`；**t−1 收盘出信号、`shift(1)` 后才是 t 日持仓**
   （少这一步就是 +1 天前视，收益会虚高一截）。
3. **funding 计入**（正费率=多头付空头）：逐 8h 结算；**00 点结算要记在前一日持仓上**
   （`prev_pos * f00 + pos * (f08+f16)`），长期持仓的费用差每年可达 ±5pp。
4. **fee**：0.05%/边（永续 taker）主口径，敏感度必须跑 0.025 与 0.10——趋势策略换手
   20~30 次/年，fee 翻倍常直接转负（ETH CTA 实测 +2.8% → −0.2%）。
5. **分段**：TEST `20220101-20240828` 是选型唯一依据；VAL 之后只做描述性确认。
   预注册选型规则要先写下（如"主族 TEST Sharpe 最高"）再看结果。
6. **必报三张表**：① 主族全配置（TEST/VAL/全样 Sharpe 并列）② 逐年净收益（含 B&H 基准）
   ③ 参数曲线（同一族不同时间尺度/窗口）。

## 单年暴涨必须做伪影排除（踩过 +226% 那次）

单年 >100% 的结果先别信，按顺序查：
1. **逐年 OHLC 概览**：年内极差多大（+228% 说明确实可能）；
2. **逐月路径**：看是不是连续多月同向大趋势（真）还是 1~2 个月孤峰（假）；
3. **|日收益| Top8 毛刺检查**：孤立单日 ±15% 而前后日平静 = 数据损坏；前后日同向/量级相近 = 真波动；
4. **4h 级别复核**：日线数字与 4h 原始一致才算数。

## 诚实弱点清单（结论里必须写）

- TEST 证据强度（族均值 Sharpe 是不是 ~0）；
- **时间尺度敏感性**：k=30 赚、k=90/180 亏 = 单区制拟合风险，无法排除适配特定年份；
- 回撤深度（±1 无仓位管理的趋势策略全样回撤常见 −70~−95%）；
- 收益是否由单一牛/熊年驱动（逐年表一眼可见）。

## 已确认结论（别推翻，只可细化）

- **ETH TSMOM30（±1 双向）**：全样 +30.3%/年 Sharpe 0.73、回撤 −76%；但 TEST 仅 +2.8%/年
  Sharpe 0.38（fee 0.10%/边转负），VAL +73.1%/年 Sharpe 1.14 全靠 2025 大趋势年（年内
  1,473→4,830，已排除伪影）。**与 B&H 日相关 0.02，2022/2026 危机年皆正收益**。
- **40% 波动目标 overlay**：TEST Sharpe 0.38→0.76、回撤 −76%→−46%、VAL 1.24。
  趋势策略要上必带 overlay。
- 族内其他配置（TSMOM10/90/180、全部 MACROSS、DON20/55）全样皆为负或个位数——
  ETH 的趋势性集中在 30 日尺度。
- 若推进：`portfolio_4arm.py` 扩第五臂测组合增量；BTC/SOL 同族复核。

## 坑

- 4h→日线 resample 后第一根 pct_change 是 NaN，`.fillna(0)` 再乘持仓；
- DONCHIAN 用 `.ffill()` 保持状态，但要 `.shift(1)`（用 t−1 及以前的 N 日高低点）；
- 波动目标 overlay 的已实现波动要 `.shift(1)`（用 t−1 的波动定 t 的仓位）；
- long-only 变体在熊市段（2022）会把空头腿全砍掉，TEST 结果系统性差一截，属正常；
- 逐年表从预热完成日截起（SMA200 要 200 天），首年不完整要标注。
