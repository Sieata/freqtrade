# 单品种方向性策略（CTA）可行性研究套路（freqtrade 仓库）

## 先读

`RESEARCH.md` 第二十三节（ETH 首例 + SOL/DOGE 多品种复核）。工具：
`user_data/scripts/cta_research.py`（**通用**，`--sym ETH,SOL,DOGE` 或 `--sym ALL`，
`--brief` 只打汇总；ETH 专用入口 `eth_cta_research.py` 保留）。
新增品种只需 futures 目录有 `{SYM}_USDT_USDT-4h-futures.feather` 与 `-1h-funding_rate.feather`。

## 核心纪律（照抄）

1. **预注册信号族，不做搜索**。写死经典参数再跑（TSMOM k∈{10,30,90,180}、
   MACROSS {10x50,20x100,50x200}、DONCHIAN {20,55}）。事后加参数 = 挖掘，报告里要明说。
2. **日频口径**：4h K 线 `resample("1D").last()`；**t−1 收盘出信号、`shift(1)` 后才是 t 日持仓**
   （少这一步就是 +1 天前视，收益会虚高一截）。
3. **funding 计入**（正费率=多头付空头）：逐 8h 结算；**00 点结算要记在前一日持仓上**
   （`prev_pos * f00 + pos * (f08+f16)`），长期持仓的费用差每年可达 ±5pp。
4. **fee**：0.05%/边（永续 taker）主口径，敏感度必须跑 0.025 与 0.10——趋势策略换手
   20~30 次/年，fee 翻倍常直接转负（ETH CTA 实测 +2.8% → −0.2%）。
5. **分段**：TEST `20220101-20240828` 是选型唯一依据；VAL 之后只做描述性确认。
   预注册选型规则要先写下（如"主族 TEST Sharpe 最高"）再看结果。
6. **必报三张表**：① 主族全配置（TEST/VAL/全样 Sharpe 并列）② 逐年净收益（含 B&H 基准）
   ③ 参数曲线（同一族不同时间尺度/窗口）。

## 单年暴涨必须做伪影排除（踩过 +226% 那次）

单年 >100% 的结果先别信，按顺序查：
1. **逐年 OHLC 概览**：年内极差多大（+228% 说明确实可能）；
2. **逐月路径**：看是不是连续多月同向大趋势（真）还是 1~2 个月孤峰（假）；
3. **|日收益| Top8 毛刺检查**：孤立单日 ±15% 而前后日平静 = 数据损坏；前后日同向/量级相近 = 真波动；
4. **4h 级别复核**：日线数字与 4h 原始一致才算数。

## 收益集中度检验（最锋利的一刀，必做）

把 TEST 段逐日净收益排序，**剔除最赚 20 天**再算复利：

- ETH **−87.9%** / SOL **−78.8%** / DOGE **−95.2%**（三品种 TEST 段收益全在约 2% 的交易日里）；
- 同时看分年拆解：若 2022 靠单边空、2023 靠单边多、2024 就转负 → 是"吃到两次单边行情"，
  **不是可复制的趋势信号**。SOL 就是标本（+173.5% / +227.2% / −35.1%）；
- 单看 Sharpe 会被骗：SOL TEST Sharpe 1.16（三品种最高）却是最脆弱的那个。

## 水下曲线检验（持有体验，必报）

回撤深度之外必报四项：**水下天数占比**、**最长水下期**、**深于 30% 回撤的天数占比**、
**最赚 20 天发生时的水位**。判死规则：最长水下期 > 1 年且最赚 20 天大多在水下 →
行为上不可持有，直接毙，不用看 Sharpe。

- 实测三品种 TSMOM30：水下占比 **96~99%**、最长水下期 **651~1151 天**（SOL/DOGE 到样本末
  未回本）、ETH 最赚 20 天中位水位 **−20%**（最深 −68%，15/20 天在水下）；
- 与集中度检验是同一枚硬币：收益集中 2% 的日子 ⇔ 其余 98% 时间横盘阴跌 ⇔ 必须在
  最想砍仓的时刻继续持有才能等到收益。回测里"持有"免费，现实不可执行；
- 对照锚：V2 钱包口径回撤 ~32%（ddW）已是可接受上限附近，且是均值回归形态（高频小赢）。

## 诚实弱点清单（结论里必须写）

- TEST 证据强度（族均值 Sharpe 是不是 ~0）；
- **时间尺度敏感性**：k=30 赚、k=90/180 亏 = 单区制拟合风险，无法排除适配特定年份；
- 回撤深度（±1 无仓位管理的趋势策略全样回撤常见 −70~−95%）；
- 收益是否由单一牛/熊年驱动（逐年表一眼可见）。

## 已确认结论（别推翻，只可细化）

- **ETH TSMOM30（±1 双向）**：全样 +30.3%/年 Sharpe 0.73、回撤 −76%；但 TEST 仅 +2.8%/年
  Sharpe 0.38（fee 0.10%/边转负），VAL +73.1%/年 Sharpe 1.14 全靠 2025 大趋势年（年内
  1,473→4,830，已排除伪影）。**与 B&H 日相关 0.02，2022/2026 危机年皆正收益**。
- **40% 波动目标 overlay**：TEST Sharpe 0.38→0.76、回撤 −76%→−46%、VAL 1.24。
  趋势策略要上必带 overlay。
- 族内其他配置（TSMOM10/90/180、全部 MACROSS、DON20/55）全样皆为负或个位数——
  ETH 的趋势性集中在 30 日尺度。
- **多品种复核已做（ETH/SOL/DOGE）：三个都不成立**。收益集中于 2% 交易日（剔除最赚 20 天
  后全部 −79%~−95%），且被 1~2 次单边行情主导。跨品种相关日收益 0.22~0.53，
  三品种族均值等权组合 TEST Sharpe 仅 **0.23**、年化 −1.1% → **分散不能救弱信号**。
- 唯一保留的观察价值：ETH TSMOM30 与 B&H 日相关 0.02、2022/2026 危机年为正，
  可作组合对冲腿的**观察项**，不按"策略"立项。
- 若还要继续：先找能提高"收益天数占比"的信号（集中度是判死标准），或直接放弃此方向。

## 坑

- 4h→日线 resample 后第一根 pct_change 是 NaN，`.fillna(0)` 再乘持仓；
- DONCHIAN 用 `.ffill()` 保持状态，但要 `.shift(1)`（用 t−1 及以前的 N 日高低点）；
- 波动目标 overlay 的已实现波动要 `.shift(1)`（用 t−1 的波动定 t 的仓位）；
- long-only 变体在熊市段（2022）会把空头腿全砍掉，TEST 结果系统性差一截，属正常；
- **逐年表必须从预热完成日截起**（最长的 SMA200 要 200 天；数据起点 +200 天）。踩过：
  直接从 2021-01-01 截起会把 ETH 2021 算成 +248%（实际 +16%），整个表失真。
- 跨品种比年化一律用 TEST / VAL 分段，**别用全样本**——各币上市时间与首年涨幅差异极大
  （SOL 2021 +9147%、DOGE 2021 +2898%），全样本年化被起点主导。
- 单年暴涨先查伪影再采信：逐年 OHLC + 逐月路径 + |日收益| Top8 前后日 + 4h 复核。
